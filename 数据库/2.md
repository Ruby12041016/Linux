# MySQL 学习笔记二


# 一、数据库设计（Database Design）

## 1. 为什么需要数据库设计

数据库不仅仅是存数据。

更重要的是：

```text
合理组织数据
避免数据冗余
提高查询效率
保证数据一致性
```

---

错误设计：

| student_name | class_name |
|--------------|------------|
| 张三 | 软件工程1班 |
| 李四 | 软件工程1班 |
| 王五 | 软件工程1班 |

如果班级改名：

```text
软件工程1班
↓
计算机1班
```

需要修改很多行数据。

这种问题称为：

```text
数据冗余(Data Redundancy)
```

---

正确设计：

学生表：

```text
student
```

班级表：

```text
class
```

分别存储。

---

# 二、实体（Entity）

现实世界中的对象称为实体。

例如：

```text
学生(Student)
班级(Class)
教师(Teacher)
课程(Course)
用户(User)
订单(Order)
商品(Product)
```

---

数据库设计原则：

```text
一个实体对应一张表
```

例如：

```text
学生
↓
student表

班级
↓
class表
```

---

# 三、数据库关系

数据库中的表与表之间存在关系。

主要有三种：

```text
一对一（1:1）
一对多（1:N）
多对多（M:N）
```

---

# 四、一对一（One To One）

## 概念

一条数据对应另一条数据。

例如：

```text
一个学生
对应
一个身份证
```

---

关系：

```text
Student
   ↔
ID Card
```

---

示例：

学生表：

| id | name |
|----|------|
| 1 | 张三 |

身份证表：

| id | student_id | card_no |
|----|------------|---------|
| 1 | 1 | 123456 |

---

实现方式：

```sql
student_id UNIQUE
```

保证：

```text
一个学生只能对应一个身份证
```

---

# 五、一对多（One To Many）

## 概念

最常见的关系。

例如：

```text
一个班级
多个学生
```

---

关系：

```text
软件工程1班
 ├── 张三
 ├── 李四
 └── 王五
```

---

数学表示：

```text
1 : N
```

---

## 表设计

班级表：

```sql
CREATE TABLE class(
    id INT PRIMARY KEY AUTO_INCREMENT,
    class_name VARCHAR(50)
);
```

---

学生表：

```sql
CREATE TABLE student(
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20),
    age INT,
    class_id INT
);
```

---

数据：

班级表：

| id | class_name |
|----|------------|
| 1 | 软件工程1班 |
| 2 | 软件工程2班 |

---

学生表：

| id | name | class_id |
|----|------|----------|
| 1 | 张三 | 1 |
| 2 | 李四 | 1 |
| 3 | 王五 | 2 |

---

含义：

```text
张三属于班级1
李四属于班级1
王五属于班级2
```

---

## 一对多实现原则

记住：

```text
外键放在“多”的一方
```

例如：

```text
一个班级
多个学生
```

因此：

```sql
student.class_id
```

作为外键。

---

# 六、多对多（Many To Many）

## 概念

双方都对应多个对象。

例如：

```text
学生
↔
课程
```

---

情况：

张三：

```text
高数
英语
数据库
```

---

李四：

```text
高数
数据库
```

---

关系：

```text
一个学生多个课程
一个课程多个学生
```

---

数学表示：

```text
M : N
```

---

# 七、中间表（Junction Table）

多对多必须使用中间表。

---

学生表：

```text
student
```

---

课程表：

```text
course
```

---

选课表：

```text
student_course
```

---

学生表：

| id | name |
|----|------|
| 1 | 张三 |
| 2 | 李四 |

---

课程表：

| id | course_name |
|----|-------------|
| 1 | 高数 |
| 2 | 英语 |
| 3 | 数据库 |

---

中间表：

| student_id | course_id |
|------------|-----------|
| 1 | 1 |
| 1 | 2 |
| 1 | 3 |
| 2 | 1 |
| 2 | 3 |

---

表示：

```text
张三选了：
高数
英语
数据库

李四选了：
高数
数据库
```

---

# 八、外键（Foreign Key）

## 为什么需要外键

假设：

学生表：

| name | class_id |
|------|----------|
| 张三 | 999 |

---

问题：

```text
999班级根本不存在
```

---

数据库允许插入：

```sql
INSERT INTO student(name,class_id)
VALUES('张三',999);
```

---

造成：

```text
脏数据
```

---

# 九、外键定义

```sql
CREATE TABLE student(
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20),
    class_id INT,

    FOREIGN KEY(class_id)
    REFERENCES class(id)
);
```

---

解释：

```sql
FOREIGN KEY(class_id)
```

表示：

```text
class_id是外键
```

---

```sql
REFERENCES class(id)
```

表示：

```text
引用class表中的id
```

---

# 十、JOIN（连接查询）

## 为什么需要 JOIN

学生表：

| id | name | class_id |
|----|------|----------|
| 1 | 张三 | 1 |

---

班级表：

| id | class_name |
|----|------------|
| 1 | 软件工程1班 |

---

需求：

```text
查询：
张三 软件工程1班
```

---

学生表没有：

```text
class_name
```

---

班级表没有：

```text
name
```

---

因此需要：

```sql
JOIN
```

把两个表连接起来。

---

# 十一、JOIN 本质

通过关联字段建立关系。

例如：

```sql
student.class_id
=
class.id
```

---

关系：

```text
student
    ↓
class_id
    ↓
class
```

---

# 十二、INNER JOIN（内连接）

## 语法

```sql
SELECT 字段
FROM 表1
INNER JOIN 表2
ON 连接条件;
```

---

示例：

```sql
SELECT student.name,
       class.class_name
FROM student
INNER JOIN class
ON student.class_id = class.id;
```

---

结果：

| name | class_name |
|------|------------|
| 张三 | 软件工程1班 |
| 李四 | 软件工程1班 |
| 王五 | 软件工程2班 |

---

特点：

```text
只保留匹配成功的数据
```

---

# 十三、LEFT JOIN（左连接）

## 语法

```sql
SELECT *
FROM A
LEFT JOIN B
ON A.id = B.id;
```

---

规则：

```text
保留左表全部数据
```

---

匹配不到：

```text
显示 NULL
```

---

示例：

学生表：

| name | class_id |
|------|----------|
| 张三 | 1 |
| 王五 | NULL |

---

结果：

| name | class_name |
|------|------------|
| 张三 | 软件工程1班 |
| 王五 | NULL |

---

记忆：

```text
LEFT JOIN
保左边
```

---

# 十四、RIGHT JOIN（右连接）

## 语法

```sql
SELECT *
FROM A
RIGHT JOIN B
ON A.id = B.id;
```

---

规则：

```text
保留右表全部数据
```

---

匹配不到：

```text
显示 NULL
```

---

记忆：

```text
RIGHT JOIN
保右边
```

---

# 十五、表别名（Alias）

原写法：

```sql
student.name
```

---

简写：

```sql
student s
```

---

然后：

```sql
s.name
```

---

完整示例：

```sql
SELECT s.name,
       c.class_name
FROM student s
INNER JOIN class c
ON s.class_id = c.id;
```

---

# 十六、多表 JOIN

三张表：

```text
student
class
college
```

---

关系：

```text
student
   ↓
class
   ↓
college
```

---

查询：

```sql
SELECT s.name,
       c.class_name,
       co.college_name
FROM student s
INNER JOIN class c
ON s.class_id = c.id
INNER JOIN college co
ON c.college_id = co.id;
```

---

# 十七、JOIN + WHERE

查询：

```text
软件工程1班所有学生
```

---

SQL：

```sql
SELECT s.name
FROM student s
INNER JOIN class c
ON s.class_id = c.id
WHERE c.class_name='软件工程1班';
```

---

# 十八、聚合查询

## COUNT

统计数量。

```sql
SELECT COUNT(*)
FROM student;
```

---

# 十九、GROUP BY

## 分组统计

数据：

| name | age |
|------|------|
| 张三 | 18 |
| 李四 | 18 |
| 王五 | 20 |

---

SQL：

```sql
SELECT age,
       COUNT(*)
FROM student
GROUP BY age;
```

---

结果：

| age | count |
|------|------|
| 18 | 2 |
| 20 | 1 |

---

含义：

```text
按照 age 分组统计
```

---

# 二十、AS（别名）

原写法：

```sql
COUNT(*)
```

---

别名：

```sql
COUNT(*) AS total
```

---

结果列名：

```text
total
```
