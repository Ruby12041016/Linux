# MySQL 学习笔记一

## 一、数据库基础概念

### 1. 什么是数据（Data）

数据是对现实世界事物的描述。

---

### 2. 什么是数据库（Database）

数据库是用于存储、管理和操作数据的软件系统。

例如：

- 学生信息管理系统
- 图书管理系统
- 电商网站
- 银行系统

都需要数据库来存储数据。

数据库的主要功能：

- 存储数据
- 查询数据
- 修改数据
- 删除数据

---

### 3. 什么是 MySQL

MySQL 是一种关系型数据库管理系统（RDBMS）。

全称：

```text
Relational Database Management System
关系型数据库管理系统
```

特点：

- 数据以表的形式存储
- 使用 SQL 语言操作数据
- 开源免费
- 应用广泛

---

### 4. 什么是 Redis

Redis 是一种 Key-Value（键值）数据库。

数据形式：

```text
name -> 张三
age  -> 18
```

特点：

- 数据存储在内存中
- 读取速度极快
- 常用于缓存

---

### 5. MySQL 和 Redis 的区别

| 对比项 | MySQL | Redis |
|----------|----------|----------|
| 类型 | 关系型数据库 | 键值数据库 |
| 数据存储方式 | 表 | Key-Value |
| 数据存储位置 | 磁盘 | 内存 |
| 查询能力 | 强 | 较弱 |
| 速度 | 较快 | 极快 |
| 适用场景 | 长期存储 | 缓存 |

---

# 八、约束（Constraint）

## PRIMARY KEY

主键。

作用：

唯一标识一条记录。

特点：

- 唯一
- 非空

---

## AUTO_INCREMENT

自增。

作用：

自动生成编号。

---

## NOT NULL

不能为空。

示例：

```sql
name VARCHAR(20) NOT NULL
```

---

## UNIQUE

唯一约束。

作用：

字段值不能重复。

---

## DEFAULT

默认值。

示例：

```sql
age INT DEFAULT 18
```

插入时不填写年龄：

```sql
INSERT INTO student(name)
VALUES('张三');
```

自动变成：

```text
18
```

---

# 九、CRUD

CRUD：

```text
Create
Read
Update
Delete
```

数据库最核心的四种操作。

---

## CREATE（新增）

### 插入数据

```sql
INSERT INTO student
VALUES(1,'张三',18);
```

---

### 推荐写法

```sql
INSERT INTO student(id,name,age)
VALUES(1,'张三',18);
```

---

### 自动编号时

```sql
INSERT INTO student(name,age)
VALUES('张三',18);
```

---

## READ（查询）

### 查询全部数据

```sql
SELECT *
FROM student;
```

---

### 查询指定字段

```sql
SELECT name
FROM student;
```

---

### 查询多个字段

```sql
SELECT name,age
FROM student;
```

---

## UPDATE（修改）

### 修改单条记录

```sql
UPDATE student
SET age = 19
WHERE id = 1;
```

---

### 危险操作

```sql
UPDATE student
SET age = 100;
```

会修改所有记录。

---

## DELETE（删除）

### 删除单条记录

```sql
DELETE FROM student
WHERE id = 1;
```

---

### 删除所有记录

```sql
DELETE FROM student;
```

仅删除数据，不删除表。

---

# 十五、模糊查询

## LIKE

查询姓张的人：

```sql
SELECT *
FROM student
WHERE name LIKE '张%';
```

---

常见通配符：

### %

任意多个字符

```sql
'张%'
```

---

### _

任意一个字符

```sql
'张_'
```

匹配：

```text
张三
张飞
```

不匹配：

```text
张无忌
```

---

# 十六、范围查询

## BETWEEN

```sql
SELECT *
FROM student
WHERE age BETWEEN 18 AND 20;
```

等价于：

```sql
WHERE age >= 18
AND age <= 20
```

---

# 十七、集合查询

## IN

```sql
SELECT *
FROM student
WHERE age IN (18,20);
```

等价于：

```sql
WHERE age = 18
OR age = 20
```
