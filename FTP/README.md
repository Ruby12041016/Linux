# FTP服务端与客户端
基于 C++、epoll IO多路复用与线程池实现的高性能、轻量级FTP服务端与客户端，完整实现FTP核心协议逻辑，支持被动传输模式，集成用户认证、目录查看、文件上传下载等核心功能，适配Linux高并发文件传输场景。

## 环境配置
基础环境要求
- 操作系统：Linux（推荐 Ubuntu 18.04/20.04/22.04）
- 编译标准：支持 C++11 及以上版本
- 编译工具：g++、make
- 工具安装命令（Ubuntu）
```c
sudo apt update
sudo apt install g++ make
```
## 编译与运行
项目无额外第三方依赖，直接使用 g++ 原生编译即可
### 1. 编译源码
#### 编译服务端程序
```c
g++ epollserver.cc -o server
```
#### 编译客户端程序
```c
g++ client.cc -o client
```
### 2. 启动程序
#### 启动服务端
```c
./server
```
### 3. 启动客户端，连接指定FTP服务端IP
#### 用法：./client 
```c
./client
```
### 4. 登录与使用
默认账号密码
- 用户名：ruby
- 密码：1204
- 支持自定义账号密码：修改服务端同目录下 account.txt 文件，格式为 用户名:密码，程序自动读取加载。若文件为空，默认启用上述测试账号。
### 5. 支持的客户端命令

| 命令 | 功能说明 | 使用格式 |
|------|----------|----------|
| PASV | 切换为FTP被动传输模式（默认模式） | PASV |
| LIST | 查询服务端当前目录所有文件（过滤隐藏文件） | ls |
| RETR | 从服务端下载文件到本地，自动防重名覆盖 | retr 远程文件名 本地保存文件名 |
| STOR | 将本地文件上传至服务端 | stor 本地文件名 远程保存文件名 |
| QUIT / exit | 退出客户端，关闭FTP连接 | quit / exit |
